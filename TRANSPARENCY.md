# Project Transparency

HubPilot started from [AutoServer](https://github.com/artificial-720/AutoServer). `ohHeyItsCon` created and maintains HubPilot, deciding its features, requirements, testing, and releases.

AI tools have been used heavily for coding, debugging, code review, test harnesses, regression checks, and documentation.

## Testing

Live beta testing used a Velocity and Paper network with Crafty Controller. Pterodactyl and Generic HTTP have controlled implementation tests, but haven't had the same live beta coverage.
