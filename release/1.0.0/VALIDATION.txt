3.5.18 carry-forward
--------------------
The 1.0.0 code payload comes from the validated 3.5.18 release candidate. Reverse-normalization checks confirmed that the release-code changes are limited to the approved version/metadata strings, author/Link wording, and added license entries.

The 3.5.18 eight-sweep report already passed archive integrity, bytecode/control-flow verification, Stop Server target identity mapping, Crafty live-discovery harness testing, Crafty start/stop HTTP integration, discovery/provider-ID repair, blast-radius review, and decision/regression review.

Testing scope note
------------------
Crafty Controller is the only external controller integration covered by live beta testing for this release. Pterodactyl and Generic HTTP have controlled implementation validation but do not yet have the same live beta coverage.

The previous 3.5.18 report listed deployment-specific live acceptance checks that were not separately recorded as completed. The maintainer approved proceeding with the 1.0.0 public release after the final artifact rebase and validation above.
