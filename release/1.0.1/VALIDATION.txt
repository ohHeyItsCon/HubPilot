HubPilot 1.0.1 - release validation
===================================
Date: 2026-08-24

Release change
--------------
1.0.1 adds the per-server Always-On server option.

This is separate from the Always-On provider. A server can still use Crafty, Pterodactyl, Generic HTTP, or another managed provider while being marked Always-On.

When Always-On server is enabled, HubPilot keeps provider startup available but disables its automatic shutdown paths for that server:
- idle shutdown
- failed-request shutdown
- queue-empty shutdown

Manual server stop behavior is unchanged.
